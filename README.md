# 🌸 Iris Flower Classification using ANN

## Overview
A Deep Learning project that predicts Iris flower species using an Artificial Neural Network (ANN) built with TensorFlow and Keras.

The project also includes an interactive web application developed using Streamlit.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- TensorFlow / Keras
- Streamlit

## Models
- Perceptron
- Artificial Neural Network (ANN)

## Features
- Data preprocessing and exploratory data analysis
- Label Encoding
- Feature Scaling
- ANN model training
- Model evaluation
- Real-time flower species prediction
- Prediction confidence visualization

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
